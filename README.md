# QA API Testing — Swagger Petstore

This repository contains educational API testing practice using the Swagger Petstore API.

## Technologies & Tools

* Postman
* REST API
* Swagger
* HTTP/JSON
* Test Cases
* Bug Reporting

## Covered Testing Areas

* CRUD operations
* GET / POST / PUT / DELETE methods
* Request validation
* Response validation
* Status code verification
* API collections and test runs

## Tested Endpoints

* /pet
* /store/order
* /user
* /user/login
* /pet/findByStatus
* /pet/findByTags

## Example Test Scenarios

* Create user
* Update pet information
* Find pet by ID
* Delete user
* Login validation
* Order management

## Purpose

Educational QA project created during software testing training at ITMO University.
